# Shell, basics

Two-line Bash scripts for the Holberton School Shell projects.

- `0-current_working_directory`: Print the absolute path of the current directory.
- `1-listit`: List the current directory.
- `2-bring_me_home`: Change to the current user home directory.
- `3-listfiles`: List files in long format.
- `4-listmorefiles`: List all files, including hidden files, in long format.
- `5-listfilesdigitonly`: List all files with numeric user and group IDs.
- `6-firstdirectory`: Create my_first_directory in /tmp.
- `7-movethatfile`: Move betty into my_first_directory.
- `8-firstdelete`: Delete the exercise file betty.
- `9-firstdirdeletion`: Remove the empty exercise directory.
- `10-back`: Change to the previous working directory.
- `11-lists`: List the current, parent and boot directories.
- `12-file_type`: Identify the type of /tmp/iamafile.
- `13-symbolic_link`: Create a symbolic link to /bin/ls.
- `14-copy_html`: Copy missing or newer HTML files to the parent directory.
- `15-lets_move`: Move files starting with an uppercase letter to /tmp/u.
- `16-clean_emacs`: Delete editor backup files ending in a tilde.
- `17-tree`: Create the nested welcome/to/school directories.
