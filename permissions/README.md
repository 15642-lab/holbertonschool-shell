# Shell, permissions

Two-line Bash scripts for the Holberton School Shell projects.

- `0-iam_betty`: Switch to user betty.
- `1-who_am_i`: Print the effective username.
- `2-groups`: Print the current user groups.
- `3-new_owner`: Change the owner of hello to betty.
- `4-empty`: Create an empty hello file.
- `5-execute`: Add owner execute permission.
- `6-multiple_permissions`: Add owner and group execute permission and other read permission.
- `7-everybody`: Add execute permission for everyone.
- `8-James_Bond`: Give only other users all permissions.
- `9-John_Doe`: Set hello permissions to rwxr-x-wx.
- `10-mirror_permissions`: Copy olleh permissions to hello.
- `11-directories_permissions`: Add execute permission to immediate subdirectories only.
- `12-directory_permissions`: Create my_dir with mode 751.
- `13-change_group`: Change hello group to school.
- `14-change_owner_and_group`: Change owner and group of entries in the current directory.
- `15-symbolic_link_permissions`: Change the symbolic link owner and group without following it.
- `16-if_only`: Change hello owner only when its current owner is guillaume.
